Bạn có thể nhập nhiều API Key cùng lúc để tăng tốc độ dịch.

Chức năng này sẽ tự động chuyển hướng bạn sang trang dịch thuật tài liệu chính thức của Google Translate với các tùy chọn ngôn ngữ đã chọn sẵn.

  • Dịch toàn tệp tin: Hỗ trợ .pdf, .docx, .pptx, .xlsx hoàn toàn miễn phí.
  • Bảo toàn bố cục: Bản dịch sẽ xuất ra file PDF/Word có vị trí hình ảnh, font chữ giống hệt bản gốc.
  • Không cần API Key: Dịch trực tiếp từ hệ thống của Google không lo hết hạn ngạch.
Hướng dẫn: Bấm nút "Mở Google Translate Documents" bên dưới. Khi trang mới mở ra, bạn chỉ cần tải tệp lên và bấm "Dịch" (Translate).
